# FireCAD downloads

**Download FireCAD for Windows:** https://firecad.github.io/firecad-releases/

Or go straight to the installer: https://github.com/FireCAD/firecad-releases/releases/latest/download/FireCAD-win-Setup.exe

FireCAD is fire alarm and security drawing software for Windows 10 and 11 (64-bit). It needs a licence key to activate: start a free 7-day trial or subscribe (£80 + VAT a month, which includes 2 users and 2 computers) with the buttons on the page above. Questions: info@firecad.co.uk.

## What is in this repository

This repository holds **only builds and the download page**. There is no source code here.

| What | Where |
|---|---|
| The download page | `index.html` (shown at the address above by GitHub Pages) |
| The program: installer, update packages, update feed | the **Releases** tab (`FireCAD-win-Setup.exe`, `FireCAD-<version>-full.nupkg`, `releases.win.json`, ...) |

Installed copies of FireCAD look at the newest release here when they start, and offer to update.

## Installing

1. Download `FireCAD-win-Setup.exe` (the big button on the page above).
2. Open it from your browser's download bar. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. FireCAD is not yet signed with a paid certificate.
3. FireCAD installs for your Windows user in a few seconds and opens. Type your licence key and click **Activate**.

Uninstall from Windows **Settings > Apps > Installed apps > FireCAD**.
